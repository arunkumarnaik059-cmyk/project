I implemented a backend search and ranking service for an e-commerce platform focused on electronic products, mainly iPhones.
The goal of the project was to design a product search engine that can return relevant and ranked results based on different types of user queries.

The service is built using Node.js and Express and stores the product catalog in memory for fast access and low latency. Each product contains core attributes such as title, description, price, rating, stock, and flexible metadata like model, color, storage, and year.

The search API accepts a user query and:

Normalizes the input to handle spelling mistakes (e.g., ifone → iphone)

Supports Hinglish queries like “sasta iphone”

Extracts numeric intent for budget-based searches (e.g., iphone 50000)

Matches products using token-based relevance

Applies intent-aware ranking by considering price, rating, stock, and metadata

Differentiates between phones and accessories such as covers and chargers

Products are ranked using a custom scoring algorithm, ensuring that results align with real user intent (for example, cheaper products are ranked higher for budget queries).


The APIs are designed to be simple, modular, and extensible, and the project demonstrates practical backend engineering skills, search logic design, and real-world problem solving.
